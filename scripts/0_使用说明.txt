 SRM 自瞄 使用说明
==============================================================

当前状态 (2026-10-29 实测)
------------------------------------------------------------
  静止靶      命中率 100%
  低速旋转靶  命中率  75%
  超高转速    ❌ 跟不上(可观性不足, 已知限制)

  5 米距离标定完成:
    off_pitch = 3.7 度   (枪口在相机下方 + 5m 下坠 253mm)
    off_yaw   = 0.0 度
    伺服方向  yaw = -1   pitch = +1


快速开始
------------------------------------------------------------

  第一步: 调参 (需要看画面时用)

      cd ~/myaim
      ./1_调参.sh

    会弹出三个窗口:
      camera   图传 + 检测框 + 绿色十字
      params   发出去什么 / 收到什么 / 差多少
      knobs    所有滑条

    >>> 调好后必须按 s 保存 <<<
    然后按 q 退出。


  第二步: 开火

      cd ~/myaim
      ./2_开火.sh

    然后:
      1) 遥控器打开自瞄       -> mode 变 1
      2) 手动对准装甲板       -> locked 变 1
      3) 等 [FIRE] 开火 这行  -> 我们的请求已发出
      4) 按人工许可键         -> 子弹出膛


注意
------------------------------------------------------------

  * 两个脚本不能同时跑! 相机和串口是独占的。
    脚本开头会自动 pkill 掉旧的, 但别手动开两个终端跑。

  * 启动第一屏会打印 [EFFECTIVE], 那是本次实际生效的全部参数。
    如果 offset / dir 和你想的不一样, 说明参数文件没存上或没读到。

  * 参数优先级: 命令行 > aim_params.cfg > config.hpp
    调参脚本保存的是 aim_params.cfg。

  * 报错 "相机打不开" / 错误码 -2147483133
    是有别的进程占着相机, 执行:  pkill -f 'build/'

  * 报错 "mode=0"
    自瞄没开。遥控器拨一下。mode=0 时下位机完全忽略我们的角度指令。


参数含义(常用)
------------------------------------------------------------

  conf        检测置信度     漏检就降, 误检(锁灯/反光)就升
  enemy       敌方颜色       0=蓝 1=红 2=不过滤
  off yaw     水平瞄准偏移   滑条 100 = 0 度, 每 10 格 = 1 度
  off pitch   俯仰瞄准偏移   同上。落点偏低就往大调
  dirYaw      伺服方向       -1 或 +1
  dirPitch    伺服方向       -1 或 +1
  gain        伺服增益       抖就降, 迟钝就升 (1.0 起)
  deadband    死区           小偏角当 0, 防抖
  measLP      实测角低通     8~14 之间比较合适


换算(5 米处)
------------------------------------------------------------

  1 度 = 87 mm
  装甲板 140 x 125 mm
  开火容差 = 0.6 x 板角宽 = 0.9 度
